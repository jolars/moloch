This release adds a new ltx-talk version of the theme, multiple standout styles, and fixes a few minor issues. For a full list of changes, see below.

## [2.3.0](https://github.com/jolars/moloch/compare/v2.2.0...v2.3.0) (2026-10-15)

### Highlights

Moloch is now also available as a [ltx-talk](https://www.texdev.net/ltx-talk/) theme! The theme is still experimental but please feel free to try it out and report any issues you encounter.
